# Contributions

kleulir is developed by one person, and **pull requests are not accepted**. A pull
request opened here will be closed without review. This keeps the copyright of the
whole code base with a single author.

- **Bugs and requests:** open an issue. There is no promise of a reply or a fix.
- **Your own changes:** fork the repository. The licence (GPL-3.0-or-later, see
  [LICENSE](LICENSE)) lets you change kleulir and pass it on, provided what you pass
  on stays under the same licence and comes with its source.
