Other libraries
---------------
Each has its licence in this folder, in a file named after it:

  curl               libcurl.dll
  openssl            libcrypto-3-x64.dll
  zlib, zstd, brotli, bzip2      compression
  freetype, harfbuzz             text rendering
  icu                            Unicode support
  libjpeg-turbo, libpng          image decoding
  md4c, pcre2, double-conversion used by Qt
  nlohmann-json                  compiled into kleulir.exe

These were built from source with vcpkg (https://github.com/microsoft/vcpkg);
each port's recipe there names the exact upstream source.
